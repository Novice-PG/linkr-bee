# Linkr TUI 使用教程

适用版本：**linkr 1.0.0**（`linkr-bee-tui` 仓库 `feat/linkr-tui-redesign` 分支，CI 全平台构建）

本目录内容：

| 文件 | 说明 |
|---|---|
| `linux/` | Linux 安装包与压缩包（`.deb`：amd64 / arm64 / armhf / i386；`.tar.gz`：x86_64 / aarch64） |
| `windows/` | Windows 压缩包（x86_64 msvc / gnu、ARM64、i686，解压即用） |
| `macos/` | macOS 压缩包（Apple Silicon / Intel，解压即用） |
| `SHA256SUMS` | 全部产物的校验和 |
| `使用教程.md` | 本文件 |

Linkr TUI 是一个跑在电脑终端里的程序，用来连接 **Linkr Bee 桥**：看串口输出、查板子状态、给板子配网、管理日志上传，还带一个查看 AI 助手会话与任务的面板。

---

## 一、快速开始

### Linux（.deb 安装包）

按机器架构选择：`amd64`（常见 PC）、`arm64`（ARM 服务器/新树莓派）、`armhf`（32 位 ARM 开发板）、`i386`（32 位 x86 老机器）。

```sh
sudo apt install ./linux/linkr_1.0.0_arm64.deb    # 换成你机器对应的文件名
linkr --version                                   # 应输出 linkr 1.0.0
linkr                                             # 启动界面
```

不用包管理器也行：`sudo dpkg -i linux/linkr_1.0.0_arm64.deb`，若有依赖提示再 `sudo apt-get -f install`。
安装包依赖系统自带的 `libdbus-1-3`（桌面发行版基本都已装好），并要求 glibc ≥ 2.39（对应 Ubuntu 24.04、Debian 13 及以后；更老的系统 apt 会直接提示依赖不满足）。

非 Debian 系发行版（Fedora、Arch 等）用压缩包，glibc 要求同上：

```sh
tar xzf linux/linkr-1.0.0-x86_64-unknown-linux-gnu.tar.gz   # arm64 机器换成 aarch64 那份
./linkr-1.0.0-x86_64-unknown-linux-gnu/linkr --version
```

### Windows

解压对应系统的包，进入解压出的目录：

| 系统 | 文件 |
|---|---|
| 64 位 Windows（推荐） | `windows/linkr-1.0.0-x86_64-pc-windows-msvc.tar.gz` |
| 64 位 Windows（备选） | `windows/linkr-1.0.0-x86_64-pc-windows-gnu.tar.gz`（功能相同；哪份跑不起来就换另一份） |
| Windows on ARM（骁龙本） | `windows/linkr-1.0.0-aarch64-pc-windows-msvc.tar.gz` |
| 32 位 Windows | `windows/linkr-1.0.0-i686-pc-windows-gnu.tar.gz` |

```powershell
.\linkr.exe              # 启动界面
.\linkr.exe --scan       # 列出附近蓝牙设备
```

Windows 自带的 `tar.exe`（Win10 1803 起）即可解压；也可用 7-Zip。

### macOS

按芯片选一份（M 系列用 `aarch64`，Intel 用 `x86_64`）：

```sh
tar xzf macos/linkr-1.0.0-aarch64-apple-darwin.tar.gz
./linkr-1.0.0-aarch64-apple-darwin/linkr
```

首次运行若被 Gatekeeper 拦下，在「访达」里右击 → 打开，允许一次就行。
`macos/README.md` 里还有在这台 Mac 上源码构建的方法。

### 启动之后

- 之前连过的板子：自动按记住的蓝牙地址重连；
- 第一次：自动扫描附近蓝牙设备——只发现一台 Linkr 板子就直接连上，发现多台会列出清单（↑↓ 选择，Enter 连接）。

> 需要系统蓝牙已开启（Linux 下 BlueZ 正常运行时一般无需额外配置）。

## 二、界面结构

```
┌ 顶栏：● 状态 · BLE/LAN 传输 · 地址 · RX/TX 速度图 ────────────────┐
│ 侧栏                 │ 主区（F2 终端 / F3 诊断 / F4 网络 / F5 助手）│
│  连接                │                                              │
│  视图                │                                              │
│  快捷发送            │                                              │
│  监控                │                                              │
├ 底栏：Ctrl+P 面板 · F1 帮助 · F2-F5 视图 · Ctrl+Q 退出 ───────────┤
└ 右下角：通知（toast），结果与问题都从这里说一声 ──────────────────┘
```

- 顶栏状态圆点：**○** 未连接 · **◐** 连接中 · **●** 已连接 · **◆** 失败；右侧是收（绿）/发（蓝）速度图。
- 侧栏（`Ctrl+↑` 聚焦，`Esc` 返回主区）：连接区（状态、传输方式、连接/断开、切换设备）、视图区、快捷发送（Enter 发送，`reboot` 之类会先确认）、监控区。
- 右下角通知会自动消失；`Ctrl+P` 面板里可以翻看历史通知。

## 三、键位速查

| 按键 | 作用 |
|---|---|
| `F1` | 帮助 / 命令速查（↑↓ 选择，PgUp/PgDn 翻页，Enter 直接发送选中的命令） |
| `F2` / `F3` / `F4` / `F5` | 终端 / 诊断 / 网络 / 助手 视图 |
| `Ctrl+P` | 命令面板（所有动作的入口，输入即筛选） |
| `Ctrl+Q` | 退出 |
| `Ctrl+↑` / `Esc` | 聚焦侧栏 / 退回主区 |
| `Ctrl+T` | 主题选择小窗 |
| `Ctrl+L` | 清空终端屏 |
| `Ctrl+Shift+R` / `C` / `A` | 给**下一个**按键加 Shift / Ctrl / Alt 修饰后发给板子 |
| `Ctrl+Shift+Y` | 把当前屏幕复制到系统剪贴板（OSC 52） |
| `Ctrl+Shift+V` | 粘贴剪贴板内容 |
| `Ctrl+C` | 有连接时向板子发中断；无连接时退出 |
| 鼠标滚轮 / `PgUp`·`PgDn` | 终端视图翻历史；诊断视图翻页 |

## 四、四个视图

### F2 终端
键进去什么就发给板子什么；板子的回显与输出都画在这里。往上翻历史会暂停「自动跟随最新」，回到最底或**一打字**就恢复跟随。

相关命令行选项：

- `--local-echo` 本机回显；
- `--line-mode` 整行按下 Enter 才发送；
- `--enter cr|lf|crlf|raw` 把 Enter 翻译成指定字节再发。

### F3 诊断
按 **`r`** 向桥发 `@i?`，把返回的 `@info` 行画成与 web 端一致的表格（固件、系统、UART、WiFi、上传……）。8 秒内没有回音就报超时（与 web 行为一致）。`PgUp`/`PgDn` 翻页；新的一次读取会回到顶部。

> 管理读取是 BLE 专属：LAN 连接下该视图会说明为什么读不了。

### F4 网络（配网与上传）
- **WiFi 状态行**：Enter 查询（`@w?`）；「扫描」列出板子能看到的网络（`@w scan`）；「连接」输入 SSID 与密码并下发（`@w=…`）；「断开」忘记网络（`@w off`）。
- **配网是事件驱动的**：从排队 → 连接中 → DHCP → 已连接（带 IP）/ 失败（带错误码），全过程由桥主动上报的事件自动刷新，不需要手动重查；若 45 秒内没有最终结果，会自动补一次 `@w?` 兜底。
- **WebDAV 行**：查看/设置日志上传地址（`@d?` / `@d=`）、关闭上传（`@d off`）。

### F5 助手
查看这台设备的 AI 助手会话、任务列表与设备笔记，并配置模型端点：

- `Ctrl+Shift+K` 聚焦输入框，输入任务后 Enter 提交（未配置端点时会提示先去配置）；
- `Ctrl+Shift+S` 打开设置窗口（端点、模型等字段 + 笔记）；
- `Ctrl+Shift+M` 切换模式；`Ctrl+Shift+N` 清空会话。

### 关于 `@` 管理命令
`F1` 帮助里的「命令速查」列着常用命令（`@i?` `@u?` `@w?` `@d?` `@s?` 及扫描、开关等），Enter 即发。板子的任何答复里若带 token，**上屏前一律打码**（`token=***`），通知与日志同样处理。

## 五、命令行用法（不打开界面也能干活）

> 下文示例里的 `linkr` 指已安装的程序（Windows 下写作 `linkr.exe`）。

**一次性查询**（连接 → 问 → 打印 → 退出）：

```sh
linkr --scan                        # 列出附近蓝牙设备
linkr --query-info                  # @i?
linkr --query-uart                  # @u?
linkr --query-wifi                  # @w?
linkr --query-webdav                # @d?
linkr --json --quiet --query-wifi   # 脚本用：JSON Lines，适合管道
```

**配网与上传**：

```sh
linkr --wifi "MySSID,MyPassword"    # 连接 WiFi（SSID,密码）
linkr --wifi "MySSID" --wifi-key-file pw.txt   # 密码改为从文件第一行读
linkr --wifi-scan                   # 扫描网络
linkr --wifi-off                    # 忘记网络
linkr --webdav http://host:port/u   # 设置上传地址
linkr --webdav-off                  # 关闭上传
```

**连接方式**：

```sh
linkr --ble-address EE:C7:42:34:48:CF   # 指定蓝牙地址
linkr --ble-name "UART-3"               # 按名字片段找
linkr --lan-host 192.168.0.102          # 走局域网 WebSocket（也可给完整 ws:// URL）
linkr --lan-token <TOKEN>               # 该桥要求的 token；也支持 --lan-token-file 或 $LINKR_LAN_TOKEN
linkr --transport ble|lan|stdio         # 锁定传输方式（锁定后界面里不可切换）
```

**其它**：

```sh
linkr --cli-then-tui --query-wifi   # 先跑一次查询，再留在界面里
linkr --no-terminal --query-info    # 只跑命令，不进界面
linkr --print-frame 100x30          # 渲染一帧文本（没有真终端时预览界面）
linkr --lang zh|en                  # 界面语言
linkr --theme dark|light|nord|gruvbox|dracula|solarized
linkr --view terminal|diagnostics|network|assistant   # 打开即停在这个视图
linkr --overlay help|palette|notices|confirm|wifi|webdav|settings   # 预览某个窗口
linkr --uart baud,data,parity,stop,flow   # 设置 UART 参数
linkr --loopback-test               # 回环自测
linkr --bridge -                    # 回环桥：离线试用界面
```

## 六、记录与排查

- `--log-file 文件`：把板子发出的每个字节追加写盘（会话留档）。
- `--debug-io`：跟踪**两个方向**的字节。
  - stderr 被重定向到文件/管道时，直接写 stderr；
  - 在终端里运行时写 `$TMPDIR/linkr-trace-<进程号>.log`（权限 0600），启动时弹通知告知路径；
  - 命令面板里也可以随时开关。
- 常见现象：
  - `le-connection-abort-by-local`：断开连接时 BlueZ 的常见日志，**正常现象**，不是故障。
  - 扫不到板子：板子不总是广播；连过一次的设备按地址直连更稳（程序会替你做）。
  - 查询/诊断超时：管理命令的窗口是 8 秒；板子忙时再按一次 `r` 即可。
  - token 只以打码形式出现；记得的 token 存在 `~/.config/linkr/lan-tokens`（0600），不会进日志与通知。

## 七、拿到后自测清单

先校验完整（Linux/macOS：`sha256sum -c SHA256SUMS`；Windows：`certutil -hashfile <文件> SHA256` 对照 `SHA256SUMS`），然后：

```sh
linkr --version                    # 应输出 linkr 1.0.0
linkr --print-frame 100x30         # 无终端也能看一帧
linkr --bridge -                   # 回环桥：离线浏览界面
linkr --scan                       # 能看到 Linkr 板子
linkr --query-info --transport ble --ble-address XX:XX:XX:XX:XX:XX
linkr                              # 界面里试：F3 按 r 出表格 / F4 查询 WiFi / Ctrl+T 换主题 / F1 帮助
```
