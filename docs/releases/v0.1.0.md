Linkr Bee 项目级发布 **{{TAG}}**：与 `radxa/linkr-bee` 上游 `main` 对齐后的第一个统一版本。固件、Web、Android 调试 APK 和桌面终端全部从同一提交 `{{SHA}}` 构建，版本统一为 `{{FIRMWARE_VERSION}}`。

### 本次包含

- **新增 Linkr Bee X1.0（MV013）板型。** 支持 RGB 状态灯、光耦干接点开关和 NEC 红外收发；板级能力由 devicetree 决定，其他板型不会出现无效控件。
- **串口输出多客户端共享。** BLE 与 LAN 客户端可以同时观察同一路 UART 输出，输入侧由单写者仲裁；慢速客户端队列满时丢弃字节并计数，不再断开连接。
- **板上 AI 配置与指令存储。** AI 配置和自定义指令保存在板子的 NVS 中，跟随板子而不是某一个浏览器；固件只保存不透明字节，由客户端负责 schema。
- **MCP 与助手增强。** Web/移动端新增 MCP 服务、客户端密钥与模型导入、板上 AI 设置；终端断线后自动重连。
- **C5 桥接与 WiFi 扫描修复。** C5 的桥接输出更稳定，扫描超时独立可配；只读查询不再抢占 UART 写权限。
- **WROOM-32 与上游一致。** 使用 Zephyr 4.4.1 + Zephyr SDK 1.0.1 构建，DRAM/RAM 配置按上游 WROOM 方案收敛。

### 刷写与校验

固件包包含镜像、最终配置、ELF/MAP、板型元数据、镜像校验和及刷写脚本。解压对应板型的 ZIP，在目录中执行：

```sh
python3 -m pip install esptool
sh flash_firmware.sh --port /dev/ttyUSB0
```

脚本按镜像名选择芯片与写入地址，并保留设置分区。下载本发布页的 `SHA256SUMS` 与所需附件，用 `sha256sum`（Linux）或 `shasum -a 256`（macOS）逐项比较；`release-manifest.json` 记录附件大小、SHA-256、组件版本、提交和构建来源。

### 平台说明

- C3/C5 默认要求首次配对时 GPIO1 接地，配对完成后释放；已绑定主机可直接重连。
- WROOM-32 默认关闭物理配对授权检查，附近主机均可申请配对；加密与绑定要求仍保留，WebDAV 因 DRAM 限制关闭。
- WebDAV 当前仅支持匿名 HTTP。Web Bluetooth 需要兼容的 Chrome/Chromium/Edge 与 HTTPS 或 localhost；Linux Firefox 可通过局域网 WebSocket 桥接使用终端。
- macOS 包未做开发者签名与公证；本次不提供 iOS IPA 或 HarmonyOS HAP。

### English

Project release **{{TAG}}** of Linkr Bee, aligned with `radxa/linkr-bee` upstream `main`. Every attachment is rebuilt from commit `{{SHA}}` and every component reports version `{{FIRMWARE_VERSION}}`.

Highlights: the new Linkr Bee X1.0 (MV013) board with RGB status LED, optocoupler dry contact and NEC IR; serial output shared by multiple BLE/LAN clients with single-writer input arbitration; board-stored AI configuration and custom instructions in NVS; the MCP server, AI settings rework and automatic client reconnect; C5 bridge output and WiFi scan deadline fixes; and a WROOM-32 configuration aligned with upstream.

Choose the firmware ZIP for your exact board, `bee` for the interactive terminal, or `bee-cli` for scripts and agent sessions. Each firmware ZIP contains the image, ELF, map, final config, flashing script, board metadata and checksums. Verify downloads against this release's `SHA256SUMS`; `release-manifest.json` provides provenance.

C3/C5 require GPIO1 low for new pairing. WROOM-32 permits pairing without a physical authorization gate and has WebDAV disabled. WebDAV on supported boards accepts anonymous HTTP only. Web Bluetooth needs a Chromium-based browser; Firefox can use the LAN WebSocket bridge. macOS packages are not Developer ID signed or notarized. No iOS IPA or HarmonyOS HAP is included.
